二、申请的权限

权限用途触发时机可否拒绝
android.permission.VIBRATE
轻触振动		 泡泡爆裂、整串掉落、触线警告时的触感反馈，属于游戏内表现效果。 仅在玩家操作（发射、消除、掉落）时由游戏进程触发，不后台运行。 可拒绝。游戏内「设置 → 轻触振动（手机）」关闭后不再使用，游戏完全可玩。

该权限属于普通权限，安装时授予、无需运行时弹窗，不涉及任何个人信息。

三、未申请的权限

以下常见权限均未在 AndroidManifest.xml 中声明，审核时可直接比对：

  • INTERNET、ACCESS_NETWORK_STATE、ACCESS_WIFI_STATE——不联网，因此不声明网络与网络状态权限。
  • READ_EXTERNAL_STORAGE、WRITE_EXTERNAL_STORAGE、READ_MEDIA_*——不读写共享存储，存档位于应用私有目录。
  • ACCESS_FINE_LOCATION、ACCESS_COARSE_LOCATION——不获取位置。
  • CAMERA、RECORD_AUDIO、MODIFY_AUDIO_SETTINGS——不使用摄像头与麦克风。
  • READ_CONTACTS、READ_SMS、READ_CALL_LOG、READ_PHONE_STATE、GET_ACCOUNTS——不读取联系人、短信、通话记录、设备状态与账号。
  • SYSTEM_ALERT_WINDOW、REQUEST_INSTALL_PACKAGES、QUERY_ALL_PACKAGES——不弹窗覆盖、不诱导安装、不查询已安装应用列表。
  • POST_NOTIFICATIONS——无推送与通知功能。

四、第三方 SDK 目录

SDK 名称提供方功能采集信息
无。当前发布版本未集成任何第三方 SDK，包括统计分析、广告变现、账号登录、支付、推送、社交分享、实名认证与防沉迷 SDK。

说明两点，便于核对：

  • 开发环境中存在 TapTap SDK 的脚本包装文件，用于后续可选接入；它未随本版本安装包分发，运行时不会被初始化，也不产生任何数据行为。
  • 构建阶段使用的工具（Godot 引擎、GDScript 混淆插件 GDMaim）只在开发机上运行，不进入安装包，不接触用户设备。

五、数据流示意

本应用的数据闭环完全在设备内部：

环节情况
输入屏幕触控、键盘与系统返回手势，仅在当前界面内处理，不落盘、不外发。
处理关卡规则、碰撞与消除计算全部在设备 CPU 本地完成。
存储应用私有目录下的 progress.cfg（进度、成绩、设置），其他应用不可读。
输出画面绘制与扬声器/振动反馈。
上传无。不存在任何形式的数据上传、日志回传或崩溃收集。
